# CO2RR Catalyst Studio 2.7.0 (Windows)

Desktop software for CO2 reduction (CO2RR) catalyst studies with the FAIRChem UMA machine-learning potential:
adsorption on slab and cluster models, the three best configurations with VASP and Gaussian 16 inputs,
CO2RR mechanisms to C1–C3 products with transition states, and energy profiles in eV and kcal/mol.

## Download

Open **[Releases](../../releases)** and download:

| File | What it is |
|---|---|
| `Software_Installation_v2.7.0_autoinstall.exe` | Automatic installer: double-click and wait (recommended) |
| `Software_Installation_v2.7.0.exe` | Normal installer: choose the folder and the options yourself |
| `CO2RR_Studio_Quick_Setup_Guide.pdf` | Two-page setup guide: start here |
| `Software_Manual_v2.7.0.pdf` | Full user manual (English and Vietnamese) |

## Requirements

Windows 10 or 11 (64-bit), about 10 GB free on drive C:, internet during installation.
An NVIDIA GPU is used automatically if present.
